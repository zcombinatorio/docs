## Overview

Launches a new SPL token on the Combinator Dynamic Bonding Curve (DBC). The token is created with a pumpfun-like bonding curve paired with SOL, and migrates to a Meteora DAMM V2 pool upon reaching the graduation threshold.

**Curve parameters:**
- **Starting mcap:** ~30 SOL
- **Migration FDV:** ~400 SOL
- **SOL raised at migration:** ~170 SOL (2x pumpfun liquidity ratio)
- **Token supply:** 1B (6 decimals)
- **Trading fee:** 1%
- **Post-migration pool fee:** 1%

The token mint authority is retained by the protocol, allowing additional tokens to be minted after launch.

## Authentication

This endpoint requires an API key passed in the `x-api-key` header. Contact the team to obtain an API key.

## Request Parameters

<ParamField body="name" type="string" required>
  Token name (e.g. "MyToken")
</ParamField>

<ParamField body="symbol" type="string" required>
  Token ticker symbol (e.g. "MTK")
</ParamField>

<ParamField body="uri" type="string">
  Pre-built metadata URI pointing to a JSON file following the Metaplex token metadata standard. Required if `image` is not provided.
</ParamField>

<ParamField body="image" type="string">
  Image URL to embed in token metadata. The server will build and upload the metadata JSON to IPFS via Pinata. Required if `uri` is not provided.
</ParamField>

<ParamField body="description" type="string">
  Token description for metadata. Only used when `image` is provided (ignored if `uri` is set).
</ParamField>

<ParamField body="recipientWallet" type="string">
  Solana wallet address to receive 100M minted tokens upon launch. If omitted, no additional tokens are minted beyond the 1B curve supply.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Whether the launch was successful
</ResponseField>

<ResponseField name="tokenMint" type="string">
  The new token's mint address
</ResponseField>

<ResponseField name="config" type="string">
  The DBC config address used for the launch
</ResponseField>

<ResponseField name="signature" type="string">
  Transaction signature for the pool creation
</ResponseField>

<ResponseField name="mintSignature" type="string">
  Transaction signature for the token mint to recipient (only present if `recipientWallet` was provided)
</ResponseField>

<ResponseField name="metadataUrl" type="string">
  The metadata URI used for the token
</ResponseField>
