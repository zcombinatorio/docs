## Overview

Streams real-time monitor events over Server-Sent Events (SSE).

<Warning>
This endpoint is served by the **Monitor API** at `https://api.percent.markets/cmb`, not by `https://api.zcombinator.io`.
</Warning>

## Base URL

- Monitor API (correct): `https://api.percent.markets/cmb`
- Z Combinator API (not this endpoint): `https://api.zcombinator.io`

## Endpoint

`GET /events`

## Authentication

No API key is required for `/events`. It is a public stream endpoint.

<CodeGroup>

```bash curl
curl -N https://api.percent.markets/cmb/events
```

```javascript browser
const source = new EventSource('https://api.percent.markets/cmb/events');

source.addEventListener('CONNECTED', (e) => {
  console.log('connected', JSON.parse(e.data));
});

source.addEventListener('COND_SWAP', (e) => {
  console.log('trade', JSON.parse(e.data));
});

source.addEventListener('TWAP_UPDATE', (e) => {
  console.log('twap', JSON.parse(e.data));
});
```

```python requests
import requests

with requests.get('https://api.percent.markets/cmb/events', stream=True) as r:
    for line in r.iter_lines(decode_unicode=True):
        if line:
            print(line)
```

</CodeGroup>

## Event Types

<ResponseField name="CONNECTED" type="event">
  Sent immediately after connection. Includes a `clientId`.
</ResponseField>

<ResponseField name="PRICE_UPDATE" type="event">
  Price update broadcast for tracked pools.
</ResponseField>

<ResponseField name="COND_SWAP" type="event">
  Real-time conditional market swap event for a proposal pool.
</ResponseField>

<ResponseField name="TWAP_UPDATE" type="event">
  TWAP snapshot update for one proposal across pools.
</ResponseField>

<ResponseField name="PROPOSAL_TRACKED" type="event">
  Emitted when the monitor starts tracking a proposal.
</ResponseField>

<ResponseField name="PROPOSAL_REMOVED" type="event">
  Emitted when a tracked proposal is removed (for example finalized).
</ResponseField>

<ResponseField name="REWARDS_DISTRIBUTED" type="event">
  Emitted when rewards distribution completes.
</ResponseField>


## Notes

- The stream uses standard SSE framing: `event: <NAME>` and `data: <JSON>`.
- The server sends keepalive comments periodically to keep idle connections open.
- Reconnect logic should be implemented client-side for network interruptions.
